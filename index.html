Foundation (기초)

입문자 · 4주 과정

통계학의 기본 개념부터 Python을 활용한 데이터 분석의 첫걸음까지. 수학적 배경 지식이 없어도 쉽게 따라할 수 있는 실습 중심 커리큘럼입니다.

📊 핵심 개념

  • 기술통계량: 평균, 중앙값, 표준편차의 실제 의미
  • 데이터 시각화: 히스토그램, 박스플롯, 산점도 해석
  • 확률 기초: 일상에서 만나는 확률 개념
  • Python 데이터 분석: pandas, numpy 기초 실습

🎯 실습 프로젝트

  • 학생 성적 데이터 분석 (5단계 가이드)
  • 브라우저 기반 Python 코드 실행
  • 인터랙티브 차트 생성 및 해석
📚 이론 학습 🚀 실습 시작
🔬

Developing (발전)

중급자 · 6주 과정

통계적 추론과 가설검정을 통해 데이터에서 의미 있는 인사이트를 발견하는 방법을 배웁니다. 실무에서 바로 활용할 수 있는 분석 기법들을 중점적으로 다룹니다.

🧪 통계적 추론

  • 가설검정: p-값의 올바른 해석과 활용
  • 신뢰구간: 불확실성을 표현하는 방법
  • 표본분포: 중심극한정리의 실제 적용
  • 검정력 분석: 표본 크기 결정하기

📈 분석 기법

  • t-검정, 카이제곱 검정 실무 적용
  • 상관분석과 단순회귀분석
  • A/B 테스트 설계 및 분석
📚 이론 학습 ⚡ 코드 실습
🎯

Proficient (숙련)

고급자 · 8주 과정

고급 통계 기법과 머신러닝의 기초를 마스터합니다. 복잡한 데이터 분석 문제를 해결할 수 있는 실력을 기릅니다.

🔍 고급 분석

  • 다중회귀분석: 여러 변수의 영향 분석
  • 로지스틱 회귀: 분류 문제 해결
  • 분산분석(ANOVA): 그룹 간 차이 검정
  • 비모수 통계: 분포 가정 없는 분석

🤖 머신러닝 기초

  • 지도학습: 회귀와 분류 알고리즘
  • 비지도학습: 클러스터링과 차원축소
  • 모델 평가와 검증
📚 이론 학습 📊 고급 실습

Advanced (전문가)

전문가 · 12주 과정

최신 데이터 사이언스 기법과 실무 프로젝트를 경험합니다. 업계 전문가 수준의 분석 능력을 갖추게 됩니다.

🚀 최신 기법

  • 딥러닝: 신경망과 텐서플로우
  • 시계열 분석: 예측 모델링
  • 빅데이터 처리: Spark와 분산 컴퓨팅
  • 자연어 처리: 텍스트 마이닝

💼 실무 프로젝트

  • 추천 시스템 구축
