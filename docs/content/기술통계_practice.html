기술통계 실습

데이터의 기본적인 통계량을 계산하고 해석해보세요.

학습 목표

  • 평균, 표준편차, 중앙값의 개념 이해
  • 데이터 분포의 시각화 방법 학습
  • 중심경향성과 산포도의 관계 파악

예상 인사이트

  • 평균과 중앙값의 차이로 데이터의 치우침을 파악할 수 있습니다.
  • 표준편차가 클수록 데이터가 넓게 분산되어 있습니다.
  • 히스토그램을 통해 데이터의 분포 형태를 시각적으로 확인할 수 있습니다.

실습 코드

아래 코드를 실행하고 결과를 분석해보세요:

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 샘플 데이터 생성
np.random.seed(42)
data = np.random.normal(100, 15, 1000)

# 기본 통계량 계산
mean_value = np.mean(data)
std_value = np.std(data)
median_value = np.median(data)

print(f"평균: {mean_value:.2f}")
print(f"표준편차: {std_value:.2f}")
print(f"중앙값: {median_value:.2f}")

# 히스토그램 그리기
plt.figure(figsize=(10, 6))
plt.hist(data, bins=30, alpha=0.7, color='skyblue', edgecolor='black')
plt.axvline(mean_value, color='red', linestyle='--', label=f'평균: {mean_value:.2f}')
plt.axvline(median_value, color='green', linestyle='--', label=f'중앙값: {median_value:.2f}')
plt.title('데이터 분포 히스토그램')
plt.xlabel('값')
plt.ylabel('빈도')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
