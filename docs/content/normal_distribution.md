## Concept Introduction

정규분포는 통계학에서 가장 중요한 확률분포 중 하나입니다. 종 모양의 대칭적인 곡선으로 표현되며, 평균과 표준편차 두 개의 매개변수로 완전히 정의됩니다. 많은 자연현상과 측정값들이 정규분포를 따르는 경향이 있어 데이터 분석에서 널리 사용됩니다. 중심극한정리에 의해 독립적인 확률변수들의 합은 표본의 크기가 충분히 클 때 정규분포에 근사하게 됩니다. 이러한 특성 때문에 정규분포는 통계적 추론의 기초가 되며, 많은 통계 기법들이 데이터가 정규분포를 따른다는 가정 하에 개발되었습니다. 표준정규분포는 평균이 0이고 표준편차가 1인 특별한 형태의 정규분포로, Z-점수 계산과 확률 계산에 자주 사용됩니다.

## Practical Example

파이썬을 사용하여 정규분포를 생성하고 시각화해봅시다:

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# 평균이 0이고 표준편차가 1인 표준정규분포에서 1000개의 샘플 생성
samples = np.random.normal(0, 1, 1000)

# 히스토그램과 확률밀도함수 시각화
plt.figure(figsize=(10, 6))
plt.hist(samples, bins=30, density=True, alpha=0.6, color="skyblue")

# 이론적인 확률밀도함수
x = np.linspace(-4, 4, 100)
plt.plot(x, stats.norm.pdf(x, 0, 1), "r-", lw=2, label="정규분포 PDF")
plt.title("표준정규분포")
plt.xlabel("값")
plt.ylabel("확률밀도")
plt.legend()
plt.show()
```

위 코드를 실행하면 표준정규분포의 히스토그램과 확률밀도함수가 표시됩니다. 히스토그램은 생성된 샘플의 분포를 보여주고, 빨간색 선은 이론적인 확률밀도함수를 나타냅니다.

## Common Misconceptions

- **모든 데이터가 정규분포를 따른다**: 많은 자연현상이 정규분포를 따르지만, 모든 데이터가 정규분포를 따르는 것은 아닙니다. 데이터 분석 전에 분포를 확인하는 것이 중요합니다.
- **표본의 크기가 작아도 정규분포를 가정할 수 있다**: 중심극한정리는 표본의 크기가 충분히 클 때만 적용됩니다. 일반적으로 표본 크기가 30 이상일 때 정규성을 가정할 수 있습니다.
- **이상치가 있어도 정규분포 가정이 유효하다**: 이상치는 데이터의 정규성에 큰 영향을 미칠 수 있으므로, 정규성 가정 전에 이상치 처리가 필요할 수 있습니다.
