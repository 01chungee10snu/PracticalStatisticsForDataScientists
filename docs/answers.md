# 정답 모음
각 문서의 연습 문제 해설은 다음 원칙에 따라 작성되었습니다.

1. 질문의 핵심 의도를 파악하여 간결하게 요약합니다.
2. 데이터나 사례가 필요한 경우 가능한 범위에서 구체적인 예를 제시합니다.
3. 코드가 포함된 문제는 실행 결과와 함께 해설합니다.

개별 장별 상세 해설은 향후 추가 예정입니다.

## 초급 파트 예시 해설

### 2장. 질적 연구와 양적 연구
1. **사례 연구 데이터 출처와 장점**
   - **인터뷰**: 참여자의 구체적인 경험을 수집해 상황 맥락을 깊이 있게 파악합니다.
   - **참여 관찰**: 현장 행동을 직접 기록하므로 자연스러운 자료 확보에 유리합니다.
   - **문서 자료**: 과거 기록을 통해 시간 흐름과 배경을 체계적으로 정리할 수 있습니다.
2. **탐색적 연구와 확인적 연구의 차이**
   - *탐색적 연구*는 가설 설정 이전 단계에서 현상과 변수를 정의하는 데 초점을 둡니다.
   - *확인적 연구*는 미리 제시한 가설을 통계 기법으로 검증합니다.
3. **주제 선정 시 윤리적 고려 사항**
   - 개인정보 보호를 위한 익명화와 보안 관리 방안을 마련합니다.
   - 자료 수집 동의 절차를 명확히 하여 연구 목적을 투명하게 알립니다.

### 4장. 우리가 아는 것 파악하기
1. **체계적 문헌 검토 절차**
   - 검색 전략 수립 → 문헌 선별 → 요약과 비평 → 연구 공백 도출 순으로 진행합니다.
2. **연구 공백 식별 시 주의점**
   - 방법론과 결과의 한계를 함께 살펴 기존 연구의 맥락을 이해합니다.
   - 출처 편중을 피하고 다양한 관점을 반영합니다.
3. **참고문헌 관리 프로그램 사용 장점**
   - 인용 형식을 자동 관리하여 반복 작업을 줄이고,
   - 여러 연구자가 목록을 공유할 때 편리합니다.

### 6장. 인터뷰를 통한 정보 수집
1. **성공적인 질문 구성 방법**
   - 연구 질문과 일치하도록 인터뷰 항목을 체계화합니다.
2. **익명성 보장을 위한 절차**
   - 참여자의 식별 정보를 별도 관리하고 접근 권한을 제한합니다.
3. **후속 질문(probing) 활용법**
   - 응답이 모호할 때 추가 설명을 요청하여 맥락을 풍부하게 합니다.

### 중급 파트 예시 해설

#### 직접 요인 분석 이론
1. **점수 행렬 분해의 핵심 목적**
   - 관찰된 변수 뒤에 숨어 있는 공통 요인을 추정해 차원을 축소합니다.
2. **최대 우도 추정의 이점**
   - 파라미터 수가 많아도 수렴이 비교적 안정적이며, 통계적 검정을 병행할 수 있습니다.

### 고급 파트 예시 해설

#### 통계적 기계 학습
1. **교차 검증의 필요성**
   - 모델이 훈련 데이터에 과적합되지 않았는지 평가하는 데 필수적입니다.
2. **앙상블 기법의 장점**
   - 서로 다른 모델을 결합해 단일 모델보다 예측 성능을 높입니다.
