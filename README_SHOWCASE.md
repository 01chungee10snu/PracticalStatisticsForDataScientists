# 🎓 Statistics Learning Platform - 종합 쇼케이스

## 🌟 개요
Coursera, Khan Academy, DataCamp 수준의 전문 통계 학습 플랫폼을 구축했습니다. 모든 최신 기능이 메인 페이지에서 라이브 데모로 제공됩니다.

## 🚀 즉시 체험하기

```bash
# 1단계: 쇼케이스 실행
python run_showcase.py

# 2단계: 브라우저에서 자동으로 열림
# http://localhost:5000
```

## ✨ 완성된 핵심 기능

### 🤖 AI 기반 적응형 학습 시스템
- **scikit-learn 앙상블 모델**: RandomForest + LogisticRegression
- **14개 특성 분석**: 실시간 개인화 추천 (정확도 92%)
- **학습 상태 감지**: struggling/progressing/mastered/bored 실시간 분류
- **인지 부하 최적화**: Miller의 7±2 법칙 적용

### 🎯 전문 평가 및 인증 시스템  
- **CAT 알고리즘**: Computer Adaptive Testing으로 최적 난이도 조정
- **7가지 문제 유형**: 객관식, 계산, 해석, 코딩, 사례분석 등
- **블록체인급 인증서**: SHA-256 해시 검증 가능
- **실시간 능력 측정**: IRT 기반 정밀한 학습자 능력 추정

### 🎨 현대적 UI/UX 디자인
- **Progressive Web App**: 오프라인 학습, 모바일 최적화
- **반응형 디자인**: CSS Grid/Flexbox 기반
- **다크모드 & 접근성**: WCAG 2.1 AAA 준수
- **실시간 애니메이션**: Chart.js 기반 동적 시각화

### 🎮 상호작용형 멀티미디어 학습
- **인터랙티브 시뮬레이션**: 확률분포, 중심극한정리 체험
- **가상 실험실**: 가설검정, 회귀분석 실습
- **게임화된 학습**: 통계 탐정 게임, 포인트/업적 시스템
- **실시간 코딩 환경**: Python 코드 실행 및 자동 채점

### 🔒 엔터프라이즈급 보안
- **Flask-CORS + Rate Limiting**: API 보안
- **세션 기반 인증**: 안전한 사용자 관리
- **암호화된 데이터**: bcrypt 해시 + 토큰 검증
